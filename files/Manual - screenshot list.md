## How to take and add the screenshots

1. Use a phone (portrait). Turn on signal, set the phone to light mode, and use a **test** truck and **test** data only (no real customer names or driver details you don't want staff to see).
2. Sign in with an account that has the role in the "Account" column. Get the screen into the state described, then take a screenshot (iPhone: side button + volume up; Android: power + volume down).
3. Copy each screenshot to `files/manual-screenshots/` named exactly as the ID, e.g. `S07.png` (or `.jpg`).
4. Run `powershell -ExecutionPolicy Bypass -File scripts/prepare_manual_screenshots.ps1`. It makes small copies `files/manual-screenshots/app/help_s07.jpg` (about 450 px wide, so the app stays small).
5. Run `py -3 -I scripts/build_help_screen.py screens files`.
6. In Power Apps Studio: **Media → Upload** the new `help_sNN.jpg` files (the media name must stay `help_s07` etc.), then paste the new `screens/scrHelp.txt` and Publish.
